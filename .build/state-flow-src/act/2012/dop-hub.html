The following scrutiny sheets include the distribution of all preferences counted in this election.

These tables show the distribution of preferences for each electorate.

Table 2 for each electorate shows the distribution of votes to and from each candidate. This is the table which indicates, for this subset of votes, which candidates are winning seats.
